How it runs

  • Testing — pick dates, Start loads candles in ~3-month batches and combines results (works for 1–5 year ranges).
  • Live paper — Start auto-polls during 09:15–15:30; after hours use Testing.
  • Live money — tick the box + confirm; MARKET entry + protective SL-M; strategy exit cancels SL then MARKET sell.
  • Kite 5m limit — max {{ snapshot().kiteStats.maxDaysPerCall }} calendar days (~3 months) per historical call; longer ranges auto-chunk.
  • ATM weekly CE on BUY / PE on SELL · {{ lots }} lot · champion DNA: 1R · EMA-20 · default day stop −60 · no day profit lock · Nifty SL cap 30 / Bank 45. Optional: Strict day stop (−₹2,950) · Day profit lock (+₹5,000) · pick Nifty and/or Bank.
